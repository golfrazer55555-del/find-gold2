# 골드 캐니언 — 전설의 광맥

서부 개척 시대 협곡에서 금을 캐고, 흩어진 지도 조각을 모아 전설의 광맥을 찾는 탐험 게임입니다.
고전 PC 게임 「금광을 찾아서(Lost Dutchman Mine, 1989)」 같은 장르와 플레이 방식을 참고해 **새로 만든 오리지널 게임**입니다. 이름, 인물, 지도, 그래픽, 음악은 모두 새로 만들었습니다.

PC 브라우저와 모바일 브라우저에서 같은 파일로 동작합니다. 설치나 빌드 과정이 없고, 외부 이미지나 사운드 파일도 쓰지 않습니다(그래픽과 소리는 모두 코드로 생성).

## 실행하기

- **로컬**: `index.html`을 브라우저로 열면 바로 실행됩니다.
- **GitHub Pages**: 저장소 Settings → Pages에서 이 브랜치의 루트(`/`)를 배포 대상으로 지정하면
  `https://<아이디>.github.io/find-gold2/` 주소로 PC와 휴대폰에서 바로 플레이할 수 있습니다.
- 휴대폰에서는 브라우저 메뉴의 "홈 화면에 추가"를 쓰면 전체 화면 앱처럼 실행됩니다.

## 게임 목표

1. 마을 **더스트우드**에서 물·식량·등불 기름을 준비합니다.
2. 협곡 절벽의 광산에 들어가 금맥을 캐고, 금 분석소에서 팝니다.
3. 번 돈으로 강철 곡괭이, 말, 노새, 다이너마이트 같은 장비를 갖춥니다.
4. 지도 조각 3개를 모읍니다.
   - 살롱에서 소문을 들으면 조각이 묻힌 광산이 지도에 표시됩니다.
   - 보안관의 현상수배를 받아 산적 두목을 쓰러뜨리면 한 조각을 얻습니다.
   - 마지막 조각은 유령이 나오는 깊은 광산에 있습니다.
5. 지도가 완성되면 **전설의 광맥** 위치가 드러납니다. 맨 아래층 단단한 암반 속 **황금 심장**을 캐서 금 분석소에 가져가면 승리입니다.

## 조작법

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 왼쪽을 끌기 (가상 조이스틱) |
| 행동·채굴 | E / Space (채굴은 누르고 있기) | 행동 버튼 (채굴은 누르고 있기) |
| 사격 | F 또는 마우스 왼쪽 클릭 | 사격 버튼 (가까운 적 자동 조준) |
| 다이너마이트 | Q 또는 마우스 오른쪽 클릭 | 폭약 버튼 |
| 버팀목 세우기 | T | 버팀목 버튼 (광산 안) |
| 말 타기/내리기 | R | 타기 버튼 |
| 지도 / 가방 / 메뉴 | M / I / Esc | 오른쪽 위 버튼 |
| 붕대 / 먹기 / 마시기 | H / 1 / 2 | 가방 화면 |

## 주요 시스템

- **절차적 생성**: 새 게임마다 협곡 지형, 광산 위치와 깊이, 광산 내부 갱도가 새로 만들어집니다.
- **생존**: 체력, 허기, 갈증, 독. 낮의 사막은 갈증이 빨리 오고, 물은 우물·강·지하 웅덩이에서 채웁니다.
- **광산**: 지하 1~3층. 등불 기름이 다 떨어지면 거의 보이지 않습니다. 파다 보면 천장이 무너질 수 있으니 버팀목을 세우세요. 푸른 암반은 다이너마이트로만 뚫립니다.
- **적**: 방울뱀, 전갈, 코요테(밤), 산적, 산적 두목, 박쥐, 동굴 거미, 그리고 등불 빛을 싫어하는 광부의 유령.
- **마을 건물**: 잡화점, 금 분석소(매일 시세 변동), 은행(예금 이자, 쓰러져도 안전), 살롱(소문·식사·포커), 호텔(수면·저장), 병원, 마구간(말·노새), 보안관(현상금).
- **포커**: 5장 드로우, 일대일, 한 번 교체 후 한 번 베팅. 상대마다 성향이 다릅니다.
- **사금 채취**: 사금 접시를 사면 강가에서 타이밍 미니게임으로 사금을 모을 수 있습니다.
- **낮과 밤**: 하루는 현실 시간 약 12분. 밤에는 어둡고 코요테 무리가 나옵니다.
- **저장**: 호텔·야영·광산 출입 때 자동 저장되고, 메뉴에서도 저장할 수 있습니다(브라우저 localStorage).

## 파일 구조

```
index.html        화면 구성(HUD, 터치 패드, 모달, 타이틀)
css/style.css     UI 스타일 (PC/모바일 반응형, 안전 영역 대응)
js/util.js        난수·노이즈·압축·DOM 도우미
js/audio.js       WebAudio 효과음과 배경음 합성
js/input.js       키보드·마우스·터치(조이스틱, 멀티터치 버튼) 입력
js/sprites.js     코드로 그린 픽셀 아트 타일과 스프라이트
js/world.js       지상 협곡 생성 (지형, 강, 마을, 광산, 야영지)
js/mine.js        광산 층 생성 (갱도, 금맥, 사다리, 상자, 적 배치)
js/entities.js    적 AI, 총알, 다이너마이트, 아이템, 파티클
js/poker.js       살롱 포커
js/ui.js          HUD, 건물 메뉴, 가방, 지도, 사금 채취, 타이틀
js/game.js        게임 상태, 메인 루프, 렌더링과 조명, 저장/불러오기
```
